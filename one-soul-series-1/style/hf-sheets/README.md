# Higgsfield — 3D-листы героев (вариант C)

Листы для следующих клипов Wan / Kling. Стиль — полуреалистичный 3D варианта C, не плоский 2D из `bible/`.

Сгенерированы по залоченным кадрам `style/c-*.png`. Лицо, если не узнаётся за полсекунды — брак, как в `BIBLE.md`.

| Файл | Кто | В Higgsfield Element |
|---|---|---|
| `shushen.png` | Шушэн ~54 | **Shushen** |
| `father.png` | Отец ~60 | **Father** |
| `ikhil-23.png` | Ихил 23, базовое лицо | **Ikhil-23** |
| `ikhil-28.png` | Тот же Ихил + борода + свитер | **Ikhil-28** |

## Как звать в генерации

- **Wan 2.7** (звук нам нравится): Element может проигнорироваться. Класть лист как стартовый кадр + наш голос в `audio_references`.
- **Kling 3.0 / Seedance / Cinema Studio Video**: звать по имени Element. Kling ещё требует отдельный стартовый кадр.
- **Картинки** (Nano Banana, GPT Image): звать по имени Element.

Soul не тренировать: он только для Soul V2 / Cinema и не едет в Wan / Kling.

## Замок, который нельзя потерять

- Шушэн: бордово-красный шёлковый платок с золотым пейсли, завязан под подбородком, несколько тёмных локонов; изумрудно-бирюзовое платье с лёгкой золотой вышивкой; золотые кольца / серьги-кольца / цепь.
- Отец: соль с перцем, густые брови, аккуратные усы, **без бороды**; белая рубашка, тёмно-синий жилет, золотые часы.
- Ихил-23: короткие тёмные волны, чистое лицо, кремовая рубашка.
- Ихил-28: то же лицо, короткая борода, тени под глазами, пыльно-синий свитер поверх той же рубашки. Не другого мужчину.

2D-листы `bible/01`–`04` остаются для варианта Б. Для живого C / Wan брать эти.
